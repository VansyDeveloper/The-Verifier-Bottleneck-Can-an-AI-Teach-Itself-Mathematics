# Проверки реализации v3

Область: работоспособность кода и воспроизводимость smoke. Полные модельные
эксперименты выполняются оператором после получения `artem_iclr`.

Результат: **46 тестов + 14 subtests**, отдельно **4 CUDA-теста**.
Короткая Q3-очередь на GPU: 10 заданий завершены, ZIP проверен по хешам.

| Требование плана | Реализация / проверка |
|---|---|
| Отдельный протокол; сохранить v2 | `research_v3.json`, отдельные данные/locks/очереди; исходные feedback-файлы сохранены без изменений |
| Перекрёстные START×TARGET | Точные модульные уравнения; полный correct set и кратчайшая длина; проверка исходного fixture |
| CPU-допуск данных | `research_data`: отсутствие пересечений всех правильных траекторий; поддержка программ/позиций/страт; four-TARGET fallback |
| Четыре CF/entropy условия | `research_train`: одинаковые панели, порядок, seed, checkpoint и scorer; CE остаётся в каждом условии |
| Q1 и метрики | Full/local отдельно; I, cell/joint success, обычные H1/H8/масса; atomic PLAN/APPLY; constrained и free completion |
| Точный/MC reward | Исходный kernel переиспользован; параметрические MC mean/noise и actual Adam delta; dev Taylor-проверка FP32/BF16 |
| Reward-допуск | Гейт проверяет данные/инициализацию/код; CPU и однозадачный smoke не открывают scientific pilot |
| Энтропия | Два точных разложения, boundary cases; affine-эквивалентности; positive program-temperature control |
| State-access | Только состояния выбранных префиксов; control равной token-ID длины; paired dev gate |
| State/SIGReg | Классификация modulo p; компактная проекция с путём в действия; повторные состояния усредняются; ablation и save/reload |
| Второй домен | Нелинейный list DSL; точные correct sets, маски и length transfer; только выбранная пара |
| Распараллеливание | Существующий диспетчер, один процесс/GPU; отдельные Q1–Q4; копия одного manifest и хеши конфигов |
| Подтверждение и final | Dev selection; 2 условия × 2 маски × 3 seed; отдельный immutable lock; final без обучения |
| Анализ/передача | Парный panel-bootstrap; seed/mask/init учтены; проверяемый ZIP без весов |

Проверки GPU выполняются **вне sandbox** на локальной RTX 3050 Ti (4 ГБ).
Тестовая модель — случайная однослойная Qwen3, hidden size 32.
Тесты проходят обучение, оценку и сохранение/загрузку в реальной CUDA/BF16;
reward-диагностика проверяет также FP32. Conditional training в unit smoke
использует подменённый допуск: это проверка кода после гейта, не положительный
результат state/reward гипотезы. Реальное отклонение непрошедшего гейта
проверяется отдельно.

Команды воспроизведения:

```bash
uv run python -m pytest -q
ICLR_SMOKE_DEVICE=cuda uv run python -m pytest -q tests/test_research_runtime.py
```

Измерения, хеш кода и результаты проверок — в `validation.json` и логах рядом.
A100 и Qwen3-8B локально не проверялись. Наличие CUDA smoke не устанавливает
VRAM/скорость больших прогонов и не подтверждает улучшение модели.
