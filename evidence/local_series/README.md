# Локальная серия: готовые ранги

Здесь копии результатов, которые сохранились на компьютере Артёма:
Qwen3-0.6B-Base, три обучающих seed, атомарный контроль и композиционное обучение.
Для каждого сравнения есть 300 задач на знакомых и 300 на новых полях.
Исходные файлы на компьютере не изменены; пути и SHA256 записаны в manifest.json.

```bash
python -m iclr.local_hitk --out outputs/local_hitk --plots
```

Команда строит Hit@K для всех K=1,…,125, парные различия по задачам и seed,
таблицы CSV и графики. Проверяет сохранённые Hit@1/4/8/16/32/64, соответствие
задач и число правильных программ независимым перебором. GPU не нужен.

Это вторая серия, с нормировкой по пяти допустимым операциям.
Она отличается от основной шестизапусковой серии статьи и её не заменяет.
Атомарные контроли добавлены после просмотра прежних результатов.
Сохранены лучшие правильные ранги, а не все 125 оценок каждой задачи.
Поэтому кривые можно восстановить, а заново проверить порядок всех программ нельзя.

Seed обучения берётся из исходного training config; seed запуска ранжирования
везде равен нулю и не обозначает независимое обучение.
Исторические хэш и версия токенизатора не записаны. В `source_snapshot/`
лежит текущая копия исходного кода, без утверждения о её неизменности с даты расчёта.
Веса остались в исходных `artifacts/adapters/`; их текущие хэши есть в manifest.json.

Готовые CSV и графики лежат в `results/`.
Hit@32 на знакомых полях: 43,44% → 91,56%; на новых: 36,33% → 93,78%.
Это средние по трём обучающим seed; двусторонний тест смены знаков даёт p=0,25.
