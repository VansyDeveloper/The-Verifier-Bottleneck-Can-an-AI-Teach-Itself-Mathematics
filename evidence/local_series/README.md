# Локальная вторая серия

Qwen3-0.6B-Base: три пары «атомарный контроль / композиционное обучение», по 300 задач на знакомых и новых полях. Пути и хэши исходных файлов записаны в `manifest.json`; готовые таблицы и графики лежат в `results/`.

```bash
uv run python -m iclr.local_hitk --out outputs/local_hitk --plots
```

Команда без GPU строит K=1…125 и проверяет сохранённые Hit@K, задачи и число правильных программ. Средний Hit@32: 43,44% → 91,56% на знакомых полях, 36,33% → 93,78% на новых; двусторонний p=0,25.

Здесь вероятность нормирована по пяти операциям; с основной шестизапусковой серией результаты не объединяются. Атомарные контроли добавлены после просмотра прежних результатов. Seed берётся из конфигурации обучения, а не ранжирования.
Сохранены лучшие правильные ранги; всех 125 оценок и исторического хэша токенизатора нет. `source_snapshot/` содержит текущую копию кода; её неизменность со времени расчёта не установлена.
