# Проверенные результаты 22–24 сентября 2026 года

Этот каталог добавляет к проекту три отдельные серии. Файлы опытов сохранены в `source_snapshot/` с исходными относительными путями пакета `verifier_bottleneck_codex_pack`. Такое размещение оставляет неизменными пути в сценариях, протоколах и отчётах. Состояние локального пакета при отборе файлов: `7b5f58c771f424e53c3fbf2f615e958a190aa147`. Замороженные коммиты и хеши каждого опыта указаны в его протоколе. Эти серии не являются выполнением очередей `research_v6`, описанных в корневом README ветки `artem_iclr`.

| Серия | Принятые обучения и оценки | Основной результат |
|---|---:|---|
| Отбор композиционных траекторий | 12 и 12, шесть пар | Hit@32, структурированный минус случайный: −0,0025, 95% t-интервал [−0,0227, 0,0177], точный p = 0,8125 |
| Исключённые пары операций | 78 и 78, 13 наборов | Во всех 39 наблюдаемых парных сравнениях знак отрицателен. При трёх seed точный двусторонний sign-flip test для каждого набора не даёт p ниже 0,25. Общий эффект по разным GPU не рассчитывался |
| Бонус энтропии при групповом нормированном градиенте политики | 6 и 6, три пары | Hit@32, бонус минус контроль: −0,0057, 95% t-интервал [−0,0406, 0,0292], точный p = 0,75 |

Для опыта с исключёнными парами зафиксированы 20 наборов и 120 плановых обучений. Из них 78 завершены, 36 не начаты, а шесть относятся к заранее выявленному неосуществимому набору `k=5, subset=5`. Полная матрица статусов находится в [run_index.csv](source_snapshot/reports/withheld_pairs_20260923/data/run_index.csv). Итоговый научный разбор и границы вывода приведены в [FINAL_REPORT.md](source_snapshot/reports/overnight_20260923_24/FINAL_REPORT.md). Описания первого блока внутри старых подкаталогов отражают состояние на момент их создания. Для итоговой полноты следует использовать именно `FINAL_REPORT.md` и конечную матрицу.

- `source_snapshot/reports/withheld_pairs_20260923/`: исходный и дополненный протоколы, код, тесты, таблицы всех 13 завершённых наборов, кривые Hit@K и контрольные SHA-256 архивов.
- `source_snapshot/reports/grpo_entropy_20260923/`: протокол и поправки, код, тесты, пошаговая динамика 150-шагового парного опыта и его оценки.
- `source_snapshot/artifacts/`: замороженные правила отбора, оценочные задачи и их манифесты. В частности, SHA-256 `FREEZE.json` для исключённых пар равен `99DF70CE2030C18F3E86368E1C4A86EA3704FA729C6C355EE8A90C90D1333DD2`.
- `source_snapshot/src/vbexp/`, `source_snapshot/scripts/train_action_grpo.py`, исторические каталоги `source_snapshot/artifacts/stage4_*/code/` и `source_snapshot/pyproject.toml`: использованные модули проекта и зависимости, без весов модели.
- `source_snapshot/reports/overnight_20260923_24/queue_snapshots/20260924_final/`: конечные статусы 13 очередей. Word-отчёт для университета также включён в `source_snapshot/reports/`.

`FILES_SHA256.csv` содержит путь, размер и SHA-256 каждого включённого файла, кроме самого манифеста. Копии побайтно сверены с исходным локальным пакетом. Отрицательные и незавершённые результаты не переименованы в успешные.

## Границы архива

В Git не включены веса моделей, полные сырые ранжирования, объёмные аудитные ZIP и рабочие журналы серверов. Для них сохранены хеши и квитанции в таблицах и файлах `.sha256`. Поэтому этот каталог позволяет проверить опубликованные таблицы, протоколы и код, но не является самодостаточным архивом для повторного вычисления каждой оценки модели. Полная проверка исходных ранжирований и весов требует отдельно сохранённых артефактов, перечисленных в отчётах.

В копии прошли 132 теста. Ещё два интеграционных теста требуют не включённых сюда замороженного атомарного экспорта и прежнего реестра задач. Они не объявлены успешно пройденными и исключались только при проверке компактной копии. Исходный полный пакет и его результаты этими действиями не изменялись.

Проверка компактной копии с Python 3.11 и зависимостями исходного проекта:

```text
cd evidence/local_series/verified_20260922_24/source_snapshot
python -m pytest -q reports/trajectory_diversity_20260922 reports/withheld_pairs_20260923 reports/grpo_entropy_20260923 reports/overnight_20260923_24 -k "not test_frozen_atomic_export_payload_matches_confirmation_hash and not test_prior_registry_includes_previous_holdout"
```

Сравнение 150-шагового опыта с бонусом энтропии не смешивается с наблюдательным анализом шести старых 400-шаговых журналов. Реализация нового опыта не использует clipping и не должна называться clipped GRPO. Статистическая единица для вывода есть независимое обучение, а не задача или отдельный ответ.
