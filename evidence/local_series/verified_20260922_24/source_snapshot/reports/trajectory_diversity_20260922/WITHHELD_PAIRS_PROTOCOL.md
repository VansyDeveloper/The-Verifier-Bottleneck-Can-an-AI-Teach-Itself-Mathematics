# Протокол следующего этапа: исключенные пары операций

Статус: только проект эксперимента. Обучений и оценок по этому протоколу нет.
Итоги текущего сравнения случайного и структурированного отбора не используются
для изменения правил ниже.

## Заранее выбранные условия

Из исходного пула 2250 правильных траекторий выделены 21 встречающаяся
упорядоченная соседняя пара операций. Файл `WITHHELD_PAIR_SETS.json`
фиксирует по пять конкретных наборов для k = 1, 2, 3 и 5. Наборы получены
воспроизводимой выборкой с seed 84000. Проверка допустимости оставляет
не менее 250 траекторий каждой глубины 2, 3 и 4 после исключения всех
траекторий с любой парой набора. Хеш исходного пула записан в манифесте.

Это предварительная проверка, а не гарантия сопоставимости обучающих
выборок. До запуска каждой пары условий требуется построить полные
манифесты отбора и проверить равенство по глубине, p, числу токенов ответа,
числу обучающих примеров, атомарному replay, эпохам и шагам оптимизации.
Набор, не проходящий такую проверку, нельзя заменять после просмотра
результатов. Его нужно обозначить недопустимым с указанием причины.

## Сравнение и оценка

Для каждого из 20 наборов обучение с исключением пар сравнивается с
контролем. В контроле из того же пула случайно исключают столько же
траекторий по каждому сочетанию глубины и p, сколько исключило правило
пар. Затем из оставшегося пула выбирают равный бюджет 750 траекторий,
по 250 каждой глубины. Оба условия внутри повтора начинают с одного
атомарного checkpoint, используют одинаковый обучающий seed, тот же
атомарный replay и неизмененные гиперпараметры. Планируется по три
обучающих seed на набор. Это дает 120 обучений при отсутствии
недопустимых условий. Сравнение касается состава доступных данных, а не
замены решения при неизменной задаче.

Для каждого набора до обучения отдельно создают неизменные задачи с
исключенными парами и задачи без них. Все модели данного набора оценивают
на одинаковых задачах точным ранжированием 125 программ. Основная
характеристика переноса: парная разность Hit@32 между исключением пар и
случайным исключением на задачах с соответствующими парами. Отдельно
показывают Hit@K, точность на контрольных задачах и забывание атомарных
операций. Оценочные задачи не считаются независимыми повторами обучения.
Статистическая единица внутри набора: один обучающий seed.

Необходимо заранее зафиксировать генератор оценочных задач, seed, правила
непересечения с обучающими и прежними оценочными наборами, хеши кода,
выборок и чекпойнта. Нельзя выбирать наборы пар или гиперпараметры по
итоговым оценкам. При интерпретации отдельно учитывать разброс между
наборами одного k и между обучающими seed. Нынешний файл не означает,
что данный эксперимент уже проведен.
