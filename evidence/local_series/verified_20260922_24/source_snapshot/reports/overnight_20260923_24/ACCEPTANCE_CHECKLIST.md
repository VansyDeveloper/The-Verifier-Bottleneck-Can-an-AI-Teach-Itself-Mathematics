# Контроль приёмки ночного блока

Рабочий снимок на 01:30 МСК 24 сентября. Он не заменяет итоговый отчёт. Статус каждого набора нужно обновлять по текущим квитанциям и журналам, а не по этому снимку.

| Объект | Проверка | Состояние на снимке |
|---|---|---|
| Замороженный дизайн | `verify.py`, SHA-256 `FREEZE.json`, 19 допустимых наборов и 38 000 отложенных задач | Подтверждено |
| Исходный набор `k=1, subset=1` | Архив v2, SHA-256, CRC, 1637 хешей файлов, шесть записей checkpoint | Подтверждено |
| Дополненные наборы `k=1, subset=2..5` и `k=2, subset=1..2` | Независимый анализ, шесть архивов, все хеши файлов, шесть обучений и шесть оценок на набор | Подтверждено |
| Бонус энтропии | Шесть обучений и оценок, 900 групп, 7200 ответов, точное ранжирование, архив и шесть удалённых весовых файлов | Подтверждено |
| `k=2, subset=4` | Шесть парных обучений приняты, полные оценки и архив | Оценки выполняются |
| `k=2, subset=5` | Шесть парных обучений приняты, полные оценки и архив | Оценки выполняются |
| `k=2, subset=3` | Пять обучений приняты, шестое не начато, восстановление только на той же V100 после освобождения | Ожидает свободную GPU |
| `k=3, subset=1` | Замороженные входные файлы проверены на двух серверах, новый запуск только после полного предзапуска | Не начат |
| `k=5, subset=5` | Точное выравнивание невозможно по замороженному правилу | Шесть строк `DESIGN_INFEASIBLE` |

Перед включением нового набора в результаты нужно дождаться `SET_DONE`, доказать завершение координатора и дочернего контейнера, выполнить независимый CPU-анализ и проверить все 12 заданий. Для каждой оценки нужны 1000 задач с исключёнными парами, 1000 контрольных задач, 125 программ на задачу и атомарная проверка. Архив сверяется по SHA-256, CRC и каждому хешу манифеста. Веса, исключённые из компактного архива, сверяются с инвентарём на сервере. Данные разных GPU не объединяются без отдельного анализа устройства.

Итоговый учёт к 10:00 МСК требует новых копий всех журналов очередей, 120-строчной матрицы с раздельными удалённым и архивным статусами, шестистрочной матрицы бонуса энтропии, статистики только полных пар, списка незавершённых запусков и точных команд продолжения. Числа сводной таблицы проверить командой `python reports/overnight_20260923_24/check_report.py --report reports/overnight_20260923_24/REPORT_DRAFT.md --data-root reports/withheld_pairs_20260923/data`. Проверка должна охватить каждый независимо принятый набор. Не начинать новый набор после 07:30 МСК или если он не успеет пройти полный аудит до срока. После проверки отчёта и коммита освободить advisory claims и остановить heartbeat.
