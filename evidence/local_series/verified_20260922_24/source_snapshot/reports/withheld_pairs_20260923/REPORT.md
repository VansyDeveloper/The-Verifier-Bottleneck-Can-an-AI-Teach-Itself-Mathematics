# Исключение пар операций: первый экспериментальный блок

## Вопрос и область вывода

Работа проверяет, как исключение определённой соседней пары операций из обучающих траекторий влияет на выполнение новых композиционных задач. Контрольное условие исключает такое же число траекторий случайно. Основной показатель представляет собой разность Hit@32 на общих задачах, связанных с исключённой парой. Сравнение проводится по трём парным seed. Отдельные задачи не считаются независимыми повторениями обучения.

Этот отчёт относится только к первому заранее выбранному набору `k=1, subset=1`, то есть к паре `AX1, REV`. Полный план включает 20 наборов и 120 обучений. Результат первого набора не оценивает влияние числа исключённых пар и не заменяет результаты остальных наборов.

## Замороженный дизайн

Исходный пул содержит 2250 правильных траекторий. Для каждого seed обе ветви получают по 750 композиционных траекторий, по 250 для глубин 2, 3 и 4. В ветви `withheld` из доступного пула удаляются все траектории с парой `AX1, REV`. В ветви `random` удаляется то же число траекторий в каждой ячейке `(глубина, p)`. Итоговые выборки дополнительно выровнены по `(глубина, p, число целевых токенов ответа)`. Обе ветви начинают с одного атомарного checkpoint и используют одинаковый атомарный replay, число эпох, шагов оптимизатора и целевых обучающих токенов. Состав самих композиционных задач различается. Поэтому сравнение оценивает способ формирования выборки, а не замену решения при неизменной задаче.

Для каждого набора до обучения сформированы две непересекающиеся группы по 1000 новых задач глубины 3. В основной группе хотя бы одна правильная программа содержит исключённую пару. В контрольной группе таких программ нет. Для каждой задачи точно ранжируются все 125 допустимых программ. Основной показатель есть Hit@32 на первой группе. Hit@K для всех K от 1 до 125, суммарная вероятность правильных программ, контрольные задачи и забывание атомарных операций рассматриваются отдельно как дополнительные показатели.

Первоначальное требование, чтобы каждая правильная программа основной задачи содержала исключённую пару, оказалось невыполнимым для другого заранее выбранного набора `SH1, AC1`. Проверка не приняла ни одной задачи за 10 000 попыток. До просмотра результатов обучения требование было заменено на наличие хотя бы одной правильной программы с парой. Шесть файлов, созданных до изменения, сохранены отдельно и не входят в анализ. Для первого набора 35 из 1000 основных задач имеют альтернативную правильную программу без исключённой пары. Этот факт ограничивает трактовку Hit@32 как проверки обязательного использования пары.

## Вычисление и проверка

Обучение и оценка первого блока выполняются на GPU 0 университетского сервера `ccmplanner`, Tesla V100-SXM2-32GB. Используется FP16 с FP32 мастер-весами и динамическим масштабированием градиентов. Предыдущие результаты BF16 не объединяются с этой серией. H200 и локальная RTX 5060 Ti не использовались.

Все шесть обучений завершили по 30 шагов оптимизатора. Число целевых токенов, участвующих в функции потерь, совпало между ветвями каждого seed.

| Seed | Целевые токены в каждой ветви | Траектории с парой в random | Траектории с парой в withheld | Потери random | Потери withheld |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 85000 | 87 112 | 95 | 0 | 0,883324 | 0,873804 |
| 85001 | 87 284 | 87 | 0 | 0,870483 | 0,864360 |
| 85002 | 87 032 | 98 | 0 | 0,885196 | 0,863684 |

Средняя функция потерь характеризует ход обучения, но не служит показателем композиционного переноса. Все значения в таблице конечны и сверены с квитанциями каждого запуска.

Заморозка эксперимента хранится в `artifacts/withheld_pairs_20260923/FREEZE.json`. Её SHA-256 равен `99DF70CE2030C18F3E86368E1C4A86EA3704FA729C6C355EE8A90C90D1333DD2`. SHA-256 исходного пула равен `3C2BD26D16AA7BAA0EB2D6CC277C4FFD97C189B3C3405D6CD9FFEAE325C2550F`. Коммит исходного состояния до обучения: `e1d10e5`.

Приёмка обучения требует полный checkpoint, совпадение SHA-256, конечную функцию потерь, ожидаемое число шагов и равный бюджет двух ветвей внутри seed. Приёмка оценки требует 1000 задач каждого типа, 125 неповторяющихся конечных оценок для каждой задачи, все квитанции частей, совпадение хешей и атомарную проверку. Независимый локальный анализ заново вычисляет правильность программ и показатели из сырых файлов. Неполная пара не включается в статистический вывод.

Статистическая единица есть обучение, поэтому размер парной выборки первого набора равен трём. Для основной разности рассчитываются среднее, стандартное отклонение, 95-процентный t-интервал и точный двусторонний sign-flip test. Минимальное возможное двустороннее p-значение последнего теста при трёх парах равно 0,25. Этот блок не может дать значимость на уровне 0,05 по точному тесту независимо от величины наблюдаемого эффекта.

Загрузка исходного tokenizer выдаёт предупреждение о регулярном выражении Mistral. Замороженный tokenizer одинаков для обеих ветвей. Исправление его настроек в ходе этой серии нарушило бы сопоставимость с исходным checkpoint, поэтому протокол не менялся. Выводы относятся к фактически использованной реализации.

## Результаты первого блока

Все шесть обучений и шесть полных оценок приняты. Каждая оценка содержит две группы по 1000 задач с точным ранжированием 125 программ и отдельную проверку 1000 атомарных задач. В каждой ветви удалено по 315 исходных траекторий. Число траекторий с исключаемой парой в выбранной обучающей выборке приведено выше. Оно не является числом удалённых траекторий.

| Seed | Hit@32 random, задачи с парой | Hit@32 withheld, задачи с парой | Разность withheld минус random | Hit@32 random, контроль | Hit@32 withheld, контроль |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 85000 | 0,488 | 0,119 | -0,369 | 0,634 | 0,740 |
| 85001 | 0,382 | 0,126 | -0,256 | 0,660 | 0,734 |
| 85002 | 0,355 | 0,110 | -0,245 | 0,663 | 0,737 |
| Среднее | 0,408 | 0,118 | -0,290 | 0,652 | 0,737 |

Для заранее заданного основного показателя средняя парная разность равна -0,290, стандартное отклонение трёх разностей равно 0,0686. Расчётный 95-процентный t-интервал составляет от -0,4605 до -0,1195. Точный двусторонний sign-flip test даёт p=0,25. Все три пары имеют отрицательное направление. Интервал исключает ноль при параметрической модели, но точный тест с тремя парами не позволяет отвергнуть нулевую гипотезу на уровне 0,05. Поэтому результат описывает сильное наблюдаемое снижение Hit@32 в этом наборе, а не статистически подтверждённый общий эффект исключения пар.

Средняя условная вероятность правильных программ среди 125 допустимых программ на задачах с парой составила 0,014665 в ветви random и 0,003385 в ветви withheld. На контрольных задачах соответствующие значения равны 0,049881 и 0,068345. Это дополнительные показатели. Они согласуются с различием по Hit@32 для данного набора, но не заменяют основной парный анализ. Полные кривые Hit@K для K от 1 до 125 показаны на [рисунке](data/first_block/hit_k_first_block.png). Полоса вокруг каждой кривой показывает минимум и максимум трёх seed, а не доверительный интервал.

Средняя точность атомарного выбора операции по шести отдельным оценкам составляет 0,856 для random и 0,882 для withheld. Средняя точность применения операции составляет 0,822 и 0,841. У исходного атомарного checkpoint эти значения равны 0,998 и 0,915. Следовательно, обе ветви теряют часть атомарной точности после композиционного обучения. Показатели по каждой операции и seed приведены в `data/first_block/atomic_forgetting.csv`. Различия между ветвями по атомарным задачам остаются поисковыми.

## Границы интерпретации и состояние серии

Этот результат относится к заранее выбранной паре `AX1, REV`, текущему пулу, checkpoint, FP16-протоколу и трём seed. Для остальных наборов результатов обучения пока нет. По индексу 120 запланированных обучений шесть имеют статус `DONE`, 108 имеют статус `NOT_STARTED`, ещё шесть относятся к заранее обнаруженному неосуществимому набору `k=5, subset=5` и помечены `DESIGN_INFEASIBLE`. Все шесть оценочных наборов для выполненных обучений завершены. Неосуществимый набор нельзя молча заменить новым без изменения протокола.

Три парных seed дают лишь восемь перестановок знаков. Минимальное точное двустороннее p-значение составляет 0,25. Доверительный t-интервал при таком размере выборки чувствителен к предположению о распределении разностей. Задачи внутри одной оценки не создают дополнительных независимых обучений. Контрольные задачи, вероятность правильных программ, Hit@K за пределами K=32 и атомарное забывание не были основными конечными точками. На 35 из 1000 основных задач есть альтернативная правильная программа без исключаемой пары. Поэтому снижение Hit@32 нельзя отождествлять с невозможностью выполнить операционную пару как таковую.

## Воспроизведение

Точные команды проверки, анализа и продолжения очереди приведены в [README.md](README.md). Индекс всех 120 запланированных обучений хранится в `data/run_index.csv`. Сырые оценки и журналы сохраняются в `artifacts/withheld_pairs_20260923`. Компактный [архив аудита](data/first_block/first_block_audit_v2.zip) содержит код, протокол, исходные задачи, сырые ранжирования, расчёты и журналы. Его SHA-256 записан в соседнем файле `.sha256`. Веса шести адаптеров хранятся отдельно и перечислены в архиве с SHA-256, но не входят в ZIP.
