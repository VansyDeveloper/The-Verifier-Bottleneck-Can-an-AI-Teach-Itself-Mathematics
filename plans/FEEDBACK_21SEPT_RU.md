# Исправления после review 21 сентября

Исходный предмет review — коммит `d976b30`. Файлы review лежат в
[source/21sept_iclr_feedback](source/21sept_iclr_feedback) без правок.
Здесь описана новая версия; старые данные и результаты не заменяются.

## Что изменилось в выводе

Пересчёт старого dev подтверждает контрпример из review:

| Модель / семейство | SFT raw H32 | SFT full calibration H32 | −full-bias-only H32 | −bigram-bias-only H32 | unseen-first H32 |
|---|---:|---:|---:|---:|---:|
| 0.6B / B | 7,83% | 56,00% | 66,50% | 78,67% | 69,57% |
| 0.6B / D | 4,50% | 49,00% | 70,17% | 78,83% | 69,67% |
| 8B / B | 8,33% | 58,33% | 64,50% | 72,17% | 69,57% |
| 8B / D | 7,50% | 57,50% | 68,00% | 72,83% | 69,67% |

Средние по прежним continuation seed 0/1/2. Это не новые обучения и не
закрытый тест. Bias получен только из A; для самого A — пятифолдовый crossfit.
Unseen-first использует прежний train: 79 встречавшихся программ глубины 3
и 46 невстречавшихся. Ничьи — математическое ожидание по равномерному
порядку внутри группы, **без возвращения**, а не `1-(1-m)^32`.
Контроли также дают цену на A/C: у unseen-first H32 там 0%.

Поэтому формулировка «калибровка восстановила скрытое умение» снята.
Новый вопрос: улучшилось ли после SFT использование TARGET, отдельно от
изменения распределения программ? На него старые rankings без matched-START
панелей пока не отвечают. Научных значений нового target alignment ещё нет.

## Соответствие замечаниям

| Замечание | Исправление / решение |
|---|---|
| R1: нет task-blind baseline | Raw, −bias-only, score−bias, shuffled-program-bias, train-frequency/anti-frequency/unseen-first; одинаково для обеих веток. H(K) целиком, H1/H8/H32, MRR, масса, A/C и равная смесь ABCD. Для старых checkpoint берётся именно прежний train, не новый original. |
| R2: Hit32 не измеряет условный выбор | Парный цикл `Sii+Sjj−Sij−Sji` и перебор 24 назначений. Нулевой цикл получает 1/2, ничья лучшего назначения — `1/n_maximizers`. Static prior даёт 1/2 и 1/24. Отдельно full/local/format. Все три чужих TARGET сохранены, вычисляется own-minus-wrong. Многорешённые панели явно пропускаются с причиной; новые панели уникальны. |
| R3: triple/position тривиальны | Старый блок 03 исключён из новых данных и отклоняется планировщиком. Он не выдаётся за готовую проверку переноса. Условия следующего дизайна перечислены ниже; GPU на старые задачи не тратится. |
| R4: witness почти весь из трёх эквивалентностей | Квоты по семантическим классам и первым операциям; допускается >=2 решений, один task pool для обеих веток. Глобальная affine-эквивалентность отделена от совпадения на конкретном START. Предварительная проверка реальных меток за две эпохи; сначала только fixed/balanced seed0. |
| R5: pooled bigram может кодировать позицию | Добавлены positional-unigram и positional+bigram при d3. Перенос на d4 для них запрещён. Позиционные частоты каждого train включены в полный CPU-аудит; равные суммарные частоты операций не объявляются равными позициями. |
| R6: dev_atomic в final | Atomic-файл выбирается по фазе; в binding и execution report сохраняются `phase` и `atomic_split`. Интеграционный тест сравнивает фактические ID с final_atomic. |
| R6: пустая reliable-страта | Число eligible/total, coverage, статус empty/nonempty по каждому split. Baseline на соответствующем dataset — зависимость нового обучения. До утверждения о надёжных атомарных навыках требуются >=20 случаев и >=90% semantic accuracy для каждой операции на atomic и true-intermediate. |
| R6: final открывается автоматически | Dev по умолчанию, отдельные dev/final panels для original/mask1–4/witness и обе глубины для original. Final требует неизменяемый analysis lock. Новые final-очереди только читают завершённые финальные adapter из dev, проверяя задачу/seed/режим/хеш; повторного обучения нет. |
| R6: reward pilot не научный допуск | Автоматический переход к полному reward удалён из очереди; блок 05 явно отложен. Существующие низкоуровневые kernels остаются диагностическим кодом, не допуском к эксперименту. |
| R6: множество метрик без основного контраста | До оценки закреплён local pair alignment, composition−atomic_control, равные B/D, финальный checkpoint. Парный bootstrap по START, отдельные continuation seed и маски, общий atomic init. При четырёх масках минимальное двустороннее sign-flip p=0,125. |

## Данные и ограничения witness

В новом полном пуле 5 000 witness-задач; крупнее всего одно множество
правильных программ занимает 8,32%, неизбежный первый REV — 24,5%.
4 987 задач имеют глобальную affine-эквивалентность решений, 13 — дополнительное
совпадение только на конкретном START. Полный набор прошёл отдельную проверку
перебором интерпретатора, включая все правильные траектории и минимальную глубину.

Для двух эпох seed0 квадрат частот соседних пар уменьшается с 34 351 136
до 27 611 092. Число разных выбранных программ уменьшается с 44 до 39,
энтропия — с 3,4422 до 3,2480. Поэтому вмешательство называется уменьшением
дисбаланса пар, а не максимизацией разнообразия. Оно также меняет unigram и
позиции; их частоты сохранены, изолированное воздействие только на пары не
заявляется. Критерии зафиксированы до inference; другие цели обучения пока
не добавляются к пилоту.

Все новые панели содержат четыре разных TARGET с одним START и ровно одним
решением у каждого TARGET. Внутри панели общий START разрешён, между
панелями/сплитами пересечения любых правильных траекторий запрещены, включая
исходный reference. Атомарный train переиспользован без изменений.

Маски оставлены теми четырьмя допустимыми масками размера k=3, которые были
выбраны до новых модельных результатов. Новые задачи имеют отдельную версию
и seed 20260922; seed выбора масок остаётся 20260921. Малые исчерпанные
страты исключены по CPU-preflight, а не по результатам модели.
Это не исследование всех размеров k=1,2,3,5 и не независимые atomic init.

## Что означает отложенный блок 03

У старой тройки единственный правильный ответ; у position — четыре.
Их CPU-корректность не устраняет дефект измерения. До следующего обучения
нужен **новый** frozen protocol, который одновременно обеспечивает:

- несколько разных исключённых троек и несколько позиционных разбиений пар;
- присутствие каждой составляющей пары в train, с явным учётом её позиции;
- четыре разных held-out решения на одном START, без выбора одного witness
  из многорешённого множества;
- matched controls, полную таблицу поддержки программ и малые K вместе с
  инвариантным target alignment.

В текущий приоритет этот новый эксперимент не включён: review предлагает
сначала исправить измерение и выполнить 01, затем ограниченные 02 и 04.
Код не позволит случайно отправить прежний блок 03 на A100.

## Reward и внешняя репликация

Блок 05 остаётся отложенным. До него нужны гипотеза о направлении/масштабе
обновления, MC-оценки и точный градиент при одном фиксированном checkpoint,
фактические parameter/score delta и сравнение BF16/FP32. Успешная запись
adapter этого не устанавливает. SFT-start, G=32, T=1, KL=0 — отдельный опыт,
не исправленный повтор прежнего 400-шагового GRPO.

Для условного 06 оставлены только центральная пара и fixed/balanced на
Qwen0.6 и закреплённой SmolLM2-1.7B, seed0: восемь continuation и одна новая
Smol atomic init. Он не запускается автоматически вместе с 01–04. Для
дополнительных масок или seeds нужен результат, объясняющий такой бюджет.

## Статистика и стоимость

`iclr.upgrade_analysis compare` требует одинаковые панели, dataset, модельную
базу и фазу; сравнивает пары seed, усредняет continuation seed и делает 2 000
ресэмплов START внутри B и D. CI относится к этим checkpoint и одной маске.
Четыре маски показываются отдельно и равным средним; число задач не заменяет
число независимых масок. Остальные scorer/corrections остаются вторичными.

На d3 полный prefix tree имеет 31 узел, на d4 — 156. Все новые контроли
используют сохранённые score, без повторного inference. В прежнем обучении
уже встречалась глубина 4: для блока 01 перенос A-калибровки d3→d4 нельзя
называть переносом на вообще невиданную при обучении длину. Для новых
масочных обучений train состоит из d3; это другой контекст.
